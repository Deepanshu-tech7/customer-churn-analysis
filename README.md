# 🚀 Customer Churn Analysis Dashboard

An enterprise-grade Machine Learning dashboard designed to identify customers at risk of churn and deliver actionable business insights through advanced analytics, predictive modeling, and interactive visualizations.

Built with Python, Streamlit, Scikit-Learn, and Plotly, this platform empowers businesses to monitor customer behavior, evaluate churn trends, analyze revenue risk, and make data-driven retention strategies.

## ✨ Key Highlights

🔹 AI-powered customer churn prediction

🔹 Interactive executive dashboard with real-time KPIs

🔹 Customer segmentation and cohort analysis

🔹 Advanced business intelligence visualizations

🔹 Revenue risk monitoring and retention insights

🔹 PDF report generation for stakeholders

🔹 Fully deployed and accessible via Streamlit Cloud

## 🛠️ Tech Stack

**Programming:** Python

**Data Analysis:** Pandas, NumPy

**Machine Learning:** Scikit-Learn

**Visualization:** Plotly

**Dashboard:** Streamlit

**Reporting:** ReportLab

**Version Control:** Git & GitHub

## 📊 Business Impact

This project demonstrates how machine learning can help organizations proactively identify churn risks, improve customer retention, reduce revenue loss, and support strategic decision-making through data-driven insights.
